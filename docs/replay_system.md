# Replay system

## Amber's philosophy

I've had a couple of people ask me to explain the vision behind the replay system, what it's for and roughly how it works.

Think of the replay system as like, being able to travel in time and run the current version of the GCS during a previous launch. Launch days are by far the most valuable days for testing and using the system, but we don't get many chances to test at an actual launch since they're infrequent, often have technical problems (due to lack of testing), and we have lots of different stuff to test!

The idea behind the replay system is:

> "What if we collect as much data as possible at launch days so we can emulate or replay the launch interfaces, as if we're receiving data from the launchpad and rocket again, in the exact same format with the same timing"

That way if we make a new frontend or visualisation, or change any other system, we can test the new changes incredibly thoroughly as if we're at a launch day, without having to wait for those small windows of opportunity.
