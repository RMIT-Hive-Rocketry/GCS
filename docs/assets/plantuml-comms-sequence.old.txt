@startuml
skin rose
title GCS/GSE/AV LoRa Sequence Diagram v2
skinparam sequenceMessageAlign center
participant GCS
participant GSE
participant AV
activate GCS
activate GSE
activate AV
group Pre-Launch - Loop [every 0.2s]
GCS-> GSE: State CMD w/ State Flags
note left: ID: 0x02
GSE--> GCS: Ack. and Data
note left: Alternating ID: 0x06 and 0x07 \nfor each response
GCS -> AV: State CMD
note left: ID: 0x01 \nwith continuity check CMDs
AV --> GCS: Ack. and Data
note left: Alternating ID: 0x03, 0x04, 0x05 \nfor each response
        end
note left: Including during fill \nNOTE: ID 0x05 only exisits upon Payload data intergration \nNOTE: ID 0x04 will only be sent upon GPS fix \n\nTransistion to next stage determined by GSE control pendant indicating Ignition
group Ignition - Loop [every 0.2s]
GCS-> GSE: State CMD w/ Ignition Flag
note left: ID: 0x02
GSE--> GCS: Ack. and Data
note left: Alternating ID: 0x06 and 0x07 \nfor each response
GCS -> AV: State CMD
note left: ID: 0x01
AV --> GCS: Ack. and Data
note left: Alternating ID: 0x03, 0x04, 0x05 \nfor each response
end
note left: NOTE: ID 0x05 only exisits upon Payload data intergration \nNOTE: ID 0x04 will only be sent upon GPS fix \n\nTransistion to next stage determined by flight state moving to "Launch" (0b010)
group AV determing launch - Single Shot [NOT a loop]
GCS -> GSE: State CMD
note left: ID: 0x02
GSE --> GCS: Ack. and Data
note left: ID: 0x06 or 0x07
GCS -> AV: State CMD w/ Broadcast flag set
note left: ID: 0x01
AV --> GCS: Ack. w/ Broadcast begin flag set
note left: ID: 0x03
end
note left: NOTE: If AV does not respond w/ "broadcast begin" flag set \nthen GCS shall continue to send ID 0x01 with broadcast flag \nset until AV returns with correct flags set and shall not send any packets to GSE \n\nTransition to next stage determined by GCS successful reception of ID 0x03 packet \nwith correct flags set
group AV Data Transmission - Loop [for motor burn and coasting]
AV -> GCS: Data Packet Type #1
note left: ID: 0x03
AV -> GCS: Data Packet Type #2
note left: ID: 0x04
AV -> GCS: Data Packet Type #3
note left: ID: 0x05
end
note left: NOTE: ID 0x05 only exisits upon Payload data intergration \n\n Transition to next stage self determined by FC - determination of apogee
group AV Data Transmission - Loop [during and post apogee]
AV -> GCS: Data Packet Type #1
note left: ID: 0x03
AV -> GCS: Data Packet Type #2
note left: ID: 0x04
AV -> GCS: Data Packet Type #3
note left: ID: 0x05
end
note right: Prioritising GPS Coords.
note left: NOTE: ID 0x05 only exisits upon Payload data intergration \n\n Transistion to next stage self determined by FC - rocket on ground
group AV Data Transmission - Loop [Landed/Recovery]
AV -> GCS: GPS Coords
note left: ID: 0x04
end
@enduml
