Overview

The above mute/unmute (default mute) icon can be used to toggle whether alarms play or not. The alarms themselves signify if something is wrong with connections to external devices (signified by a non-green indicator), and play in a queue from top to bottom priority (GSE, AV, GPS Fix, Dual Board). Since the GPS Fix is part of the AV device, if the former goes down, so will the latter. Click the following button to hear them in succession (same order as the below table), with 0.5 sec of silence between each (including any extended alarms):

Description of each sound:
Device loss (sorted by descending order of priority) Alarm sound Source
GSE High-pitched chord (if timeout > 5 seconds, plays in quicker succession) https://www.youtube.com/watch?v=EWnhSCFCYto
AV 1kHz square wave (if timeout > 5 seconds, plays in quicker succession) https://www.youtube.com/watch?v=W5Z-d1Zx02o
